# Script video P10 — Retrofit: Konekin

Target durasi: sekitar 6–7 menit, termasuk perpindahan file, scroll, dan demo. Bahasa: Indonesia. Baca kolom narasi; lakukan instruksi layar pada kolom sebelahnya.

## Persiapan sebelum merekam

1. Buka proyek hasil implementasi di Android Studio, lakukan Gradle Sync, lalu jalankan varian `debug` di emulator yang terhubung internet.
2. Tunggu sampai daftar nama dari API tampil. Pastikan klik nama membuka detail dan tombol/gesture Back sistem kembali ke list. Jika API gagal, jangan merekam seolah-olah data berhasil dimuat; tunggu layanan pulih, lalu buka ulang aplikasi.
3. Siapkan tab `app/build.gradle.kts`, `AndroidManifest.xml`, `model/Data.kt`, `model/Users.kt`, `network/ApiService.kt`, `network/ApiClient.kt`, `MainActivity.kt`, `DetailActivity.kt`, serta kedua layout XML.
4. Catat nama dan empat nilai employee yang akan diklik. Contoh di bawah memakai Tiger Nixon **hanya jika data tersebut memang tampil**. Sesuaikan narasi dengan respons aktual.
5. Perbesar font editor dan emulator agar tulisan terbaca. Hindari menampilkan kredensial atau tab lain saat merekam.

## Catatan pengambilan gambar

- Narasi demo hanya dibacakan setelah perilakunya benar-benar terlihat. Rekaman boleh dipotong pada perpindahan editor dan emulator agar tetap sekitar 5–7 menit.
- Jika muncul “Koneksi error”, respons list belum berhasil dimuat. Jangan mengganti dengan data lokal atau menyatakan demo berhasil. Lihat Logcat untuk mengetahui masalah respons/koneksi dan ulangi rekaman setelah layanan dapat diakses.
- Script ini adalah panduan rekaman. Pengujian UI di emulator dan perekaman video belum dilakukan oleh agen; status validasi teknis dicatat di `VERIFICATION.md`.
